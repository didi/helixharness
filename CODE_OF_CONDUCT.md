# Code of Conduct / 社区行为准则

HelixHarness welcomes participants of all backgrounds. Treat each other with respect, discuss the work rather than attacking people, and give constructive feedback.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing and posting other people's private information are not acceptable. These rules apply to Issues, pull requests and other project community spaces.

Maintainers may remove harmful content, close abusive discussions, warn participants or restrict participation. They should explain moderation decisions where doing so does not expose private information.

To report abuse privately, use GitHub's **Report content / Report abuse** controls on the relevant content or contact [GitHub Support](https://support.github.com/contact/report-abuse). Do not repost private details in a public Issue. Project maintainers moderate the repository; GitHub handles reports submitted through its platform reporting channels.

欢迎不同背景的参与者。请尊重彼此，围绕代码和问题提出建设性意见，避免人身攻击。社区不接受骚扰、威胁、歧视、性骚扰、泄露他人身份或个人信息。

维护者可移除不当内容、关闭攻击性讨论、警告或限制参与者。需要私密举报时，使用对应内容上的 GitHub 举报功能或上面的 GitHub Support 入口；不要在公开 Issue 中再次传播隐私材料。
