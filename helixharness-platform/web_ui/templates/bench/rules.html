Outcome 硬门禁

F2P 或 P2P 确定性失败时，业务结果记 0 分，但工作流质量继续独立评分；PASS 后调用 Outcome Judge，ERROR/超时标记为不确定。

Outcome 语义评分

Requirement 满足度 90%，本次交付实现质量 10%；需求满足轴必须覆盖全部冻结 Requirement，并同时引用业务校验与实现证据。默认评价生产代码，只有 Requirement 明确要求测试交付物时才评价对应测试代码。阶段产物只辅助理解和定位实现。

Workflow 语义评分

对实际存在的 Markdown 证据按四个固定轴各 25% 评分，不按固定产物数量、名称或阶段绑定评分。

Evidence Incompatibility / 证据不兼容

业务验证不确定时，该 Case 不归责且不生成正式推荐。Workflow 证据不完整时不做整条硬拦截：已有证据继续按四轴评分；一侧完全没有可评分 Workflow 证据时保留另一侧 Workflow 展示，但该 Case 双方综合分都只使用 Outcome。

工作流未完成统一为一个问题

未达到冻结执行方案合法终态，或归档所需最终证据没有形成，统一记录为 WORKFLOW_TERMINAL_FAILURE。已有产物仍按四轴评分，不把某个维度或 Workflow 总分强制记 0；它不覆盖可信 Outcome，也不单独否决推荐。任一侧工作流未完成时，双方 Efficiency 均为 N/A。
